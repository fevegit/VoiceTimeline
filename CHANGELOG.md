# Changelog

All notable changes to VoiceTimeline are documented here.

## [1.0.0] - 2026-08-02

### Added

- Native Discord toasts for voice joins, leaves and rejoins.
- Bold usernames while preserving the original native toast appearance.
- Optional colored notifications.
- Optional duration text when a user leaves.
- Configurable toast duration.
- Current-session voice timeline.
- Voice-channel context-menu access.
- Join, leave and rejoin simulation controls.
- Fully dynamic Spanish and English localization.
- Session reset and history management controls.

### Privacy

- No audio recording.
- No telemetry.
- No external network services.
